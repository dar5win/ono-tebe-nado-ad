# Оно тебе надо

Учебная вёрстка страницы аукциона вещей, в которые никто не верил. Для просмотра откройте `index.html` в браузере.

https://github.com/dar5win/ono-tebe-nado-ad

## Проверка

Автоматическая проверка вёрстки запускается после отправки изменений в ветку `main`. [Результаты GitHub Actions](https://github.com/dar5win/ono-tebe-nado-ad/actions).
